THIS FILE IS NO LONGER A HAND-ENTRY CHECKLIST. It was one for the v1.4.1 record,
before .zenodo.json existed. Since then, .zenodo.json at the repository root has
overridden what Zenodo derives from a GitHub release, and its `description`
already carries the licensing paragraph and the copyright line as formatted HTML.
Nothing below needs pasting into the web form. Edit .zenodo.json instead.

ONE THING STILL CANNOT BE AUTOMATED. Zenodo's deposit schema has a singular
`license` field -- "the selected license applies to all files in this deposition"
-- so only AGPL-3.0-or-later can come from the repository. AFTER EVERY RELEASE,
open the new record and add Creative Commons Attribution 4.0 International as a
second licence by hand. That is the whole manual step.

The version number comes from the GIT TAG, not from CITATION.cff. The v1.5.0
record is correctly labelled v1.5.0 even though CITATION.cff still said 1.4.4 at
the time, so a stale CITATION.cff does not mislabel the archive. It does mislabel
GitHub's "Cite this repository" button, which is the reason to keep it current.

Verified 2026-08-07 against https://developers.zenodo.org/ and the live records.
